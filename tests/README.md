# tests

Contiene la suite de pruebas del proyecto.

Organización y recomendaciones:
- Agrupar pruebas por módulo o por funcionalidad (p. ej. `test_users.py`, `test_events.py`).
- Usar fixtures para inicializar base de datos en memoria o mocks.
- Incluir instrucciones para ejecutar las pruebas (p. ej. `pytest`).

Propósito: garantizar calidad, evitar regresiones y facilitar refactorizaciones.
