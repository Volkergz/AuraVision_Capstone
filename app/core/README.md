# Core

## Descripción
Esta carpeta contiene la configuración central de la aplicación, incluyendo variables de entorno, constantes y configuraciones generales.

## Archivos

### `configuracion.py`
Define todas las variables de configuración de la aplicación.

- **CONEXION_BD**: String de conexión a PostgreSQL
- **TITULO_APP**: Nombre de la aplicación
- **DESCRIPCION**: Descripción de la API
- **VARIABLES_ENTORNO**: Carga variables desde `.env`
