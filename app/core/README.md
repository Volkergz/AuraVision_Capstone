# app/core

Contiene configuración y utilidades centrales que usa la aplicación.

Archivos comunes:
- `config.py`: carga y validación de configuración (variables de entorno, constantes).
- `security.py`: utilidades de seguridad (hashing, JWT, permisos).

Propósito: centralizar la configuración y las funciones transversales para facilitar su reutilización y pruebas.
